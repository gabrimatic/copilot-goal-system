# Code of Conduct

## Standard

Be direct, respectful, and technical. Keep discussions focused on the project, the evidence, and the change being proposed.

## Expected behavior

- Explain problems with reproduction steps and concrete examples.
- Keep criticism about code, docs, design, or behavior.
- Respect boundaries around private data, credentials, and security reports.
- Help keep issues and pull requests actionable.

## Unacceptable behavior

- Harassment, threats, insults, or personal attacks.
- Publishing private information, credentials, logs, or personal data without permission.
- Derailing issues or pull requests with unrelated arguments.
- Repeated bad-faith participation after maintainers ask you to stop.

## Enforcement

Maintainers may edit, hide, or remove comments, close issues, block accounts, or report abuse to GitHub when needed.
